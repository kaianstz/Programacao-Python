# Programacao-Python

Este repositório vai servir como minha base para aprender Python do início.

## Objetivo
- Estudar Python passo a passo, começando do básico.
- Registrar exercícios e exemplos de cada assunto.

## Roteiro de estudos (iniciante)
1. Instalação do Python e uso do terminal.
2. Variáveis, tipos de dados e operadores.
3. Condições (`if`, `elif`, `else`).
4. Laços (`for` e `while`).
5. Funções.
6. Listas, tuplas, dicionários e conjuntos.
7. Módulos e organização de arquivos.
8. Pequenos projetos para praticar.
